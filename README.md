# SOLMARA — Travel Poster for a Place That Isn't There

A travel poster for Solmara, an invented island where the sea glows turquoise at dusk. The poster shows the island's one landmark — the white lighthouse on the black cliff — above bioluminescent waves, under a coral sunset. The program writes the poster to `/output/entry.png` (1024×1024, deterministic).
